## 📌 Problem Overview
Urban centers across India suffer severe economic losses and gridlock during intense monsoon cloudbursts. NalaNetra couples Doppler Weather Radar (DWR) quantitative precipitation estimation, Cartosat DEM hydrological analysis, and crowdsourced citizen incident reports to optimize municipal emergency dispatch.

## 🎯 Project Goals
1. Real-time radar quantitative precipitation estimation (QPE).
2. DEM depression filling and rational runoff modeling.
3. Mobile incident reporting with automated photo depth triage.
4. Municipal officer operational dashboard for dispatch prioritization.
5. Dynamic OSRM-based navigation avoiding waterlogged corridors.
6. Cryptographic audit trail for municipal accountability.
