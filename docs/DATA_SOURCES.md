# Data provenance

No municipal survey, live radar stream or observed field-impact dataset is bundled.

| Material | Source | Use / limits |
|---|---|---|
| `data/demo/rainfall.csv` | Synthetic sequence: 36 five-minute intervals | Six rate blocks of 4, 18, 48, 68, 24 and 2 mm/h; no IMD observation attribution |
| `data/demo/drainage_network.json` | Authored three-node/three-conduit network | Conveyance/storage/blockage experiment, no Gurugram survey |
| `data/demo/terrain.json` | Synthetic 5×5 terrain grid | Relative depression utility, no street-depth claim |
| `model_results.csv`, `model_summary.json` | Calculated by `scripts/build_evidence.py` | Numerical results and mass balance, not field accuracy |
| `docs/assets/risk_experiment.png`, `priority_breakdown.png` | Matplotlib from committed inputs/code | Scenario and six-factor arithmetic, labelled on each figure |
| `review_console*.png`, `browser_check.json` | Real local three-account browser run with synthetic photos | Working API/UI evidence, not municipal operation |
| `hero.svg`, `system_architecture.svg` | Original vectors generated by script | Components and integration boundaries |
| Original logo, app images, `docs/screenshots/` | Existing team-supplied assets | Design references; sample identities/counts are not operational results |
| `docs/slides/` | Existing submitted presentation | Eight files frozen with SHA-256 manifest |
| OpenStreetMap tiles | External service with visible attribution | Context map; no flood-depth measurement |

## Operational input requirements

| Source | Required provenance |
|---|---|
| IMD rain/radar | Authorized access, product, acquisition time, coverage, quality flags, freshness |
| Terrain | Provider/license, date, resolution, vertical datum and local elevation validation |
| Municipal drainage | Owner, survey/version, topology, geometry, slopes and maintenance context |
| Closures/flood observations | Authorized source, geometry, observed/expiry time, review status, uncertainty |
| Citizen/crew captures | Consent/account, original bytes, coordinate source, capture/upload time, officer review |
| OSRM roads | Operator, OSM extract/version, vehicle profile, refresh schedule |

Keep source labels when displaying scores; do not replace missing/expired inputs with unlabeled fixtures.

`python -m scripts.build_evidence` regenerates figures/CSV/JSON. N1 blocked peak is 0.3810617427 m; clear peak is 0.0689159455 m; maximum mass residual is approximately 5.68×10⁻¹³ m³. Depth is storage volume divided by fixture storage area, not surveyed street inundation.
