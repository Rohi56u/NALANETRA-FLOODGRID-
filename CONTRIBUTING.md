# Contributing

Explain the user-visible behavior, data provenance and verification. Keep credentials, citizen data and private operational evidence out of commits. Use Python 3.12, Flutter 3.47.5 and the committed lockfile.

Run relevant Python workflow/numerical checks and Flutter analysis/tests. New permission or state logic needs failure-path verification. Regenerate figures when changing fixtures/models and retain source labels. Preserve original queued bytes/time/owner and require canonical acknowledgments.

Files under `docs/slides/` are frozen; `python -m scripts.verify_presentation` must pass. Keep contributor attribution truthful; do not fabricate authors, commits or outcomes. PRs should describe the problem, resulting behavior, checks and remaining integration limits. See [reuse notices](NOTICE.md).
